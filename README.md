# WA-Anime-bot

سام: مساعد شخصي ذكي على واتساب (فويسات، صور وPDF، تذكيرات، مهام، ملخص صباحي) ومساعد للمجموعات، مع ألعاب ونظام ممالك اختياري لمجتمعات الأنمي.

## المتطلبات

- Node.js 18 أو أحدث
- MongoDB Atlas أو MongoDB محلي
- جلسة WhatsApp محفوظة داخل مجلد `auth/`

## الإعداد

انسخ `.env.example` إلى `.env` واضبط القيم:

```env
MONGO_URI=
ADMIN_PASSWORD=
GOOGLE_API_KEY=
GEMINI_API_KEY=
SAM_BOT_AI_ENABLED=true
SAM_BOT_AI_MODEL=gemini-3.1-flash-lite
SAM_BOT_AI_TIMEOUT_MS=12000
SAM_BOT_AI_MAX_OUTPUT_TOKENS=15
SAM_BOT_AI_BILLING_COOLDOWN_MS=1800000
SAM_BOT_AI_DAILY_REQUEST_LIMIT=
SAM_BOT_AI_DAILY_TOKEN_LIMIT=
SAM_BOT_USAGE_TIMEZONE=Asia/Amman
RAPIDAPI_KEY=
RAPIDAPI_GOOGLE_IMAGES_URL=https://google-images4.p.rapidapi.com/getGoogleImages
RAPIDAPI_GOOGLE_IMAGES_HOST=google-images4.p.rapidapi.com
RAPIDAPI_GOOGLE_IMAGES_QUERY_PARAM=query
RAPIDAPI_GOOGLE_IMAGES_COUNT=10
RAPIDAPI_GOOGLE_IMAGES_IMAGE_INFO=true
RAPIDAPI_IMAGE_SEARCH_QUERY_TEMPLATE={nickname} anime character
RAPIDAPI_IMAGE_SEARCH_ENABLED=true
RAPIDAPI_MONTHLY_LIMIT=50
RAPIDAPI_IMAGE_CACHE_DAYS=30
LOG_LEVEL=info
```

`ADMIN_PASSWORD` مطلوبة للأوامر الحساسة مثل تعيين الأدمن ومنح رتب الإمبراطور.

`GEMINI_API_KEY` أو `GOOGLE_API_KEY` يفعّل ردود سام بوت الذكية عند توجيه الكلام له. إذا لم يكن أي مفتاح موجودًا أو تم ضبط `SAM_BOT_AI_ENABLED=false` سيستخدم البوت الردود المحلية الاحتياطية.

أمر المطور `/رصيد_الذكاء` يعرض استهلاك Gemini المسجل في MongoDB. لضبط النسبة المتبقية، عرّف `SAM_BOT_AI_DAILY_REQUEST_LIMIT` أو `SAM_BOT_AI_DAILY_TOKEN_LIMIT` حسب حدود مشروعك في Google.

أمر المطور `/عد_التوكن <نص>` يحسب توكنات المدخلات قبل إرسالها إلى Gemini. أما توكنات output/thinking/cached/tool-use فتسجل من رد Gemini نفسه وتظهر في `/رصيد_الذكاء`.

أمر `/ترحيب` يبحث عن العضو داخل نفس المملكة فقط. صور الترحيب تستخدم RapidAPI Google Images أولًا إذا كانت المتغيرات مضبوطة وتحت الحد الشهري، ثم ترجع إلى Bing تلقائيًا. يتم حفظ روابط الصور في MongoDB لمدة `RAPIDAPI_IMAGE_CACHE_DAYS` لتقليل استهلاك طلبات RapidAPI.

## التشغيل

```bash
npm install
npm start
```

عند التشغيل لأول مرة سيظهر QR في الطرفية. امسحه من واتساب لحفظ الجلسة في `auth/`.

## التشغيل مع PM2

```bash
npm run pm2:start
npm run pm2:logs
```

## الفحص

```bash
npm test
```

هذا الفحص يتأكد من صحة الملفات الأساسية نحويًا قبل النشر.

## أوامر المطور

هذه الأوامر مخصصة للمطور فقط، ويتم تحديده عبر `DEVELOPER_JIDS` أو الرقم الافتراضي `962795137282`.

```text
/أوامر_المطور
/اوامر_المطور
/دليل_المطور
```

يعرض دليلًا مرتبًا ومشروحًا لأوامر البوت من منظور المطور.

```text
/رمز_مملكة
/رمز_نقابة
```

ينشئ رمز فتح مملكة جديد ويرسله إلى خاص المطور. الرمز لا ينتهي بالوقت، لكنه يستهلك عند استخدامه.

```text
/فتح_مملكة <الرمز>
/فتح_نقابة <الرمز>
```

يبدأ معالج فتح المملكة عبر واتساب، ويحفظ الجلسة في MongoDB حتى تكتمل أو تُلغى.

```text
/الممالك
/تقرير_الممالك
```

يعرض تقريرًا شاملًا عن الممالك، القروبات، الأعضاء، البنك، وتواريخ العمليات الأخيرة.

## معرفة JID الخاص بك

```text
/هويتي
/معرفي
/id
```

يعرض البيانات التي يراها البوت عن رسالتك، ومنها `sender`. إذا لم يتعرف عليك أمر المطور، انسخ قيمة `sender` وأضفها إلى `DEVELOPER_JIDS` في Railway.

## المساعد الشخصي

بالخاص، أول رسالة من أي شخص تجيه رسالة تعريف قصيرة، و`/مساعدة` بتعرض كل الميزات.

- **الرسائل الصوتية:** أي فويس بالخاص يرجع نصه، ومعه خلاصة إذا كان أطول من 30 ثانية. بالمجموعات: رد على الفويس بـ `/فرغ`.
- **الصور وملفات PDF:** بالخاص تُقرأ تلقائيًا، والتعليق على الصورة يعتبر سؤالًا. بالمجموعات: رد عليها بـ `/اقرأ` أو `/اقرأ <سؤال>`.
- **الدردشة بالخاص:** ردود كاملة (ترجمة، صياغة، أسئلة عامة) بدل الردود القصيرة الخاصة بالمجموعات.
- **التذكيرات:** `/ذكرني بعد 20 دقيقة ...`، `/ذكرني بكرة الساعة 9 ...`، والمتكررة: `/ذكرني كل يوم الساعة 8 مساءً ...` و`/ذكرني كل جمعة الساعة 11 ...`.
- **المهام والملاحظات:** `/مهمة`، `/مهامي`، `/تم`، `/ملاحظة`، `/ملاحظاتي` (الشرح الكامل: `/مساعدي`).
- **الملخص الصباحي:** `/صباحي تشغيل 7` يرسل كل يوم مواقيت الصلاة وتذكيرات اليوم والمهام المفتوحة. `/مدينتي اربد` لتغيير المدينة، `/صباحي` للمعاينة، `/صباحي ايقاف` للإيقاف.
- **الردود الصوتية (ElevenLabs):** `/فويس تشغيل` يخلي سام يرد بفويس بالخاص، سواء بعتله فويس أو كتابة. لما تبعت فويس بيفهمه وبيرد عليه مباشرة بدل ما يفرّغه (للتفريغ: رد عليه بـ `/فرغ`). الردود الأطول من `ELEVENLABS_MAX_CHARS` بتضل كتابة. `/فويس ايقاف` للإيقاف. يحتاج `ELEVENLABS_API_KEY` و`ELEVENLABS_VOICE_ID`، وافتراضيًا للمطور والأدمنز فقط (`ELEVENLABS_VOICE_PUBLIC=true` لفتحه للكل).
- **الحد اليومي:** طلبات الذكاء الاصطناعي (فويس، صورة، PDF، دردشة الخاص) محدودة لكل شخص باليوم. المطور والأدمن بدون حد.
- إذا كان وضع الأعمال شغالًا، ميزات الخاص لا تعمل مع العملاء حتى لا تتداخل معه.

المتغيرات الاختيارية:

```env
ASSISTANT_DAILY_LIMIT=30                 # 0 = بدون حد
ASSISTANT_MAX_AUDIO_SECONDS=600
ASSISTANT_DEFAULT_CITY=Amman, Jordan
PRAYER_TIMES_METHOD=23                   # طريقة الحساب في AlAdhan (23 = وزارة الأوقاف الأردنية)
SAM_BOT_PRIVATE_MAX_OUTPUT_TOKENS=700
SAM_BOT_MEDIA_MAX_OUTPUT_TOKENS=1500
ELEVENLABS_API_KEY=
ELEVENLABS_VOICE_ID=
ELEVENLABS_MODEL_ID=eleven_multilingual_v2
ELEVENLABS_OUTPUT_FORMAT=opus_48000_32
ELEVENLABS_MAX_CHARS=900
ELEVENLABS_VOICE_PUBLIC=false
```

## أدوات المجموعات

- `/ملخص` أو `/ملخص 50`: ملخص آخر الرسائل لمن فاته الكلام. يحفظ البوت آخر 300 رسالة نصية لكل مجموعة بالذاكرة فقط (تضيع عند إعادة التشغيل).
- `/حماية`: عرض الحالة. `/حماية روابط تشغيل|ايقاف` و`/حماية سبام تشغيل|ايقاف` لمشرفي المجموعة في واتساب. الحذف يحتاج أن يكون البوت مشرفًا، وإلا يكتفي بالتنبيه. المشرفون مستثنون.
- `/نداء <رسالة>`: منشن لكل الأعضاء (للمشرفين).
- `/ذكر_القروب <وقت> <نص>`: تذكير ينرسل بالمجموعة، ويدعم التكرار (كل يوم، كل جمعة). `/تذكيرات_القروب` و`/الغاء_تذكير_القروب <رقم>`.

## الصفحة التعريفية

على نفس عنوان اللوحة: `/` صفحة عامة تشرح سام وفيها زر "ابدأ محادثة على واتساب" (يأخذ رقم البوت من جلسة واتساب الحالية، أو من `BOT_PUBLIC_NUMBER`)، و`/privacy` سياسة الخصوصية. لربط دومين خاص، أضفه كـ Custom Domain للخدمة في Railway.

أمر الأدمن `/حالة` يعرض اتصال واتساب وقاعدة البيانات، مدة التشغيل، الذاكرة، وعدد التذكيرات المنتظرة.
